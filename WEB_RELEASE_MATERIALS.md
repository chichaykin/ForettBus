# Forett Shuttle Web release materials

## Short description

Forett Shuttle shows Forett ↔ Beauty World shuttle departures, nearby public
bus arrival times, saved route cards and optional departure reminders.

## Resident message

Forett Shuttle is now available on iPhone and Android through a web link. Open
the link in Safari, tap Share, and choose Add to Home Screen for an app icon and
optional shuttle reminders. No account is required. Public-bus arrival times
need an internet connection.

## A4 notice copy

**FORETT SHUTTLE ON YOUR PHONE**

Scan the QR code to see the Forett ↔ Beauty World timetable, public-bus arrival
times and saved routes. On iPhone: open in Safari → Share → Add to Home Screen.
Open the installed icon and enable notifications if you want a reminder five
minutes before one selected departure.

This is an independent resident app. App support is separate from the
Management Office. Delivery time for Web Push depends on the phone, network and
iOS notification settings.
