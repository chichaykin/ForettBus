Forett Shuttle Help

Live arrivals are unavailable

Check your connection and try again. The shuttle timetable stays available offline. Public-bus times marked Scheduled are timetable estimates.

Reminders do not appear

On iPhone, install the app from Safari using Add to Home Screen, then enable notifications from the installed app. Check iPhone notification settings if permission was previously denied.

Reset local data

Removing website data clears saved cards, theme and an imported timetable on that device. Disable notifications in the app first so the server removes its subscription and pending reminder.
