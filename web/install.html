Install Forett Shuttle on iPhone

  1. Open the Forett Shuttle link in Safari.
  2. Tap Share, then Add to Home Screen. Turn on Open as Web App if it is shown.
  3. Open Forett Shuttle from its new Home Screen icon while online. Leave it open for a minute so the offline files can finish caching.
  4. In the installed app, open Profile and turn on Notification Preferences. Allow the notification prompt.
  5. On Home, tap Remind me to set one one-time reminder.

The timetable remains available without installing. iPhone reminders require the Home Screen app and iOS 16.4 or later. The notification prompt appears after your tap; its display time depends on network and iPhone notification settings.
